## Conceitos Fundamentais

### Dados

Em ciência de dados, tudo começa nos dados. Conforme mencionado na literatura sobre IA moderna, "tudo que é possível hoje, é possível apenas pela quantidade de dados disponíveis". Ferramentas e modelos são inúteis sem dados de qualidade.

### Informações

Pense em dados como peças de Lego:

- Cada comportamento de usuário, preenchimento de formulário ou prescrição médica gera dados
- Quando essas peças estão organizadas de forma lógica (como um castelo), temos dados com significado
- Quando estão desorganizadas, precisamos de ferramentas para extrair significado

### Padrões

Nem toda "bagunça" de dados é ruim. Frequentemente, apenas precisamos organizar os dados adequadamente, como alguém organizando um quarto. Isso é tão importante que existe uma área inteira chamada **Engenharia de Dados** dedicada a este trabalho.

## Tipos de Dados

Diferentes tipos de dados requerem diferentes tipos de tratamento:

**Dados Tabulares**: estruturados em formato de planilha (ex: Excel)
- Simples de trabalhar e analisar
- Seguem uma estrutura semelhante aos formatos de escritório

**Dados Não-Estruturados**: textos, imagens, áudio, vídeo
- Requerem processamento especial
- Mais desafiadores de trabalhar
- Base da revolução atual em Inteligência Artificial Generativa

## Processamento de Texto

### O Desafio Fundamental

Máquinas não podem entender textos da forma como humanos entendem. No campo do Processamento Natural de Linguagem (PNL), pesquisadores enfrentaram questões complexas:

- Como representar palavras diferentes com o mesmo significado?
- Como capacitar máquinas a entender contexto?
- Como lidar com nuances linguísticas?

Essas perguntas levaram décadas de pesquisa, mas vivemos agora um momento magnífico em análise de texto, especialmente graças à arquitetura Transformers (Vaswani et al., 2017).

## Representação de Palavras

### Word2Vec (Mikolov et al., 2013)

Uma solução revolucionária para representar palavras em espaço multidimensional:

**Processo**:
1. Cada palavra é transformada em um vetor
2. Palavras similares têm vetores mais próximos no espaço
3. O modelo aprende a formular novas palavras através operações vetoriais

**Exemplo Clássico**:
```
Rei - Homem = Rainha
```

**Similaridade de Cossenos**:
A proximidade entre palavras é calculada usando o produto vetorial. Vetores que apontam na mesma direção têm correlação mais forte.

```python
import numpy as np
from numpy.linalg import norm

A = np.array([2,1,2,3,2,9])
B = np.array([3,4,2,4,5,5])

cosine = np.dot(A,B)/(norm(A)*norm(B))
print("Cosine Similarity:", cosine)
```

## Transformers e Atenção

### "Attention Is All You Need" (2017)

Em 2017, Google publicou um paper revolucionário que mudaria radicalmente o campo da IA. A arquitetura Transformers introduce um mecanismo chamado **Atenção**.

**Analogia**:
Imagine que você tem uma dúvida de história e vai a um evento com milhares de professores. Você não perguntaria a todos eles, apenas aos professores de História. O modelo Transformers faz exatamente isso: prioriza palavras mais importantes para o contexto.

**Vantagens**:
- Captura dependências de longo alcance
- Processa sequências em paralelo (mais eficiente)
- Alcança resultados superiores em tarefas de compreensão de texto

## Implementação Prática

### Tarefa: Classificar Tweets como Ofensivos ou Não-Ofensivos

Essa é uma tarefa de classificação supervisionada que demonstra os conceitos aprendidos.

### Passo 1: Carregar e Preparar Dados

```python
import pandas as pd
from sklearn.preprocessing import LabelEncoder

df = pd.read_csv('data.csv')
df = df.rename(columns={'Irrelevant':'Target', 'ColumnName':'Text'})

column = ['Target', 'Text']
df = df[column]

le = LabelEncoder()
df.Target = le.fit_transform(df.Target)
```

**Explicação**: Computadores entendem números, não letras. O `LabelEncoder` transforma rótulos categóricos em números.

### Passo 2: Bag of Words (BoW)

```python
import numpy as np
from sklearn.feature_extraction.text import CountVectorizer

count = CountVectorizer()
docs = np.array([
    'The sun is shining',
    'The weather is sweet',
    'The sun is shining, the weather is sweet, and one and one is two'
])
bag = count.fit_transform(docs)
```

**Conceito**: Conte quais palavras aparecem e quantas vezes. Se a palavra "sol" aparece frequentemente, pode ser importante.

### Passo 3: TF-IDF (Term Frequency-Inverse Document Frequency)

```python
from sklearn.feature_extraction.text import TfidfTransformer

tfidf = TfidfTransformer(use_idf=True,
                         norm='l2',
                         smooth_idf=True)
```

**Conceito**: Um "fiscal" que verifica se uma palavra é realmente importante, não apenas frequente.

### Passo 4: Preprocessamento de Texto

```python
import re

def preprocessor(text):
    text = re.sub('<[^>]*>', '', text)
    emoticons = re.findall('(?::|;|=)(?:-)?(?:\)|\(|D|P)', text)
    text = (re.sub('[\W]+', ' ', text.lower()) + 
            ' '.join(emoticons).replace('-', ''))
    return text

df['Text'] = df['Text'].apply(preprocessor)
```

**O que faz**:
- Remove tags HTML
- Extrai emoticons
- Converte para minúsculas
- Remove caracteres especiais

### Passo 5: Tokenização

```python
from nltk.stem.porter import PorterStemmer
import nltk
from nltk.corpus import stopwords

porter = PorterStemmer()

def tokenizer(text):
    return text.split()

def tokenizer_porter(text):
    return [porter.stem(word) for word in text.split()]

nltk.download('stopwords')
stop = stopwords.words('english')
```

**Tokenização**: Dividir texto em unidades menores (palavras ou frases).

**Stemming**: Reduzir palavras à sua raiz (ex: "running" → "run").

**Stop Words**: Remover palavras irrelevantes (ex: "a", "the", "is").

### Passo 6: Divisão de Dados e Treinamento

```python
from sklearn.model_selection import train_test_split
from sklearn.pipeline import Pipeline
from sklearn.linear_model import LogisticRegression
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.model_selection import GridSearchCV

X = df.iloc[:, 1].values
y = df.iloc[:, 0].values
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.20, random_state=42)

tfidf = TfidfVectorizer(strip_accents=None,
                        lowercase=False,
                        preprocessor=None)

small_param_grid = [
    {'vect__ngram_range': [(1, 1)],
     'vect__stop_words': [None],
     'vect__tokenizer': [tokenizer, tokenizer_porter],
     'clf__penalty': ['l2'],
     'clf__C': [1.0, 10.0]},
    {'vect__ngram_range': [(1, 1)],
     'vect__stop_words': [stop, None],
     'vect__tokenizer': [tokenizer],
     'vect__use_idf':[False],
     'vect__norm':[None],
     'clf__penalty': ['l2'],
     'clf__C': [1.0, 10.0]},
]

lr_tfidf = Pipeline([('vect', tfidf),
                     ('clf', LogisticRegression(solver='liblinear'))])

gs_lr_tfidf = GridSearchCV(lr_tfidf, small_param_grid,
                           scoring='accuracy',
                           cv=5,
                           verbose=1,
                           n_jobs=-1)

gs_lr_tfidf.fit(X_train, y_train)

print(f'Best parameter set: {gs_lr_tfidf.best_params_}')
print(f'CV Accuracy: {gs_lr_tfidf.best_score_:.3f}')

clf = gs_lr_tfidf.best_estimator_
print(f'Test Accuracy: {clf.score(X_test, y_test):.3f}')
clf.predict(['love it'])
```

**Pipeline**: Encadeia múltiplos passos (vetorização e classificação) em um único objeto.

**GridSearchCV**: Testa diferentes combinações de parâmetros para encontrar os melhores.

## Modelos HuggingFace

### Usando Modelos Pré-Treinados

Frameworks HuggingFace permitem carregar modelos poderosos já treinados com apenas três linhas de código:

```python
from transformers import pipeline

pipe = pipeline(model="FacebookAI/roberta-large-mnli")
resultado = pipe("Meu texto incrível")
```

**Vantagens**:
- Modelos já treinados por pesquisadores ou grandes empresas
- Fácil de usar
- Resultados imediatos
- Comunidade ativa compartilhando modelos

**Exemplos de Modelos Disponíveis**:
- RoBERTa (Facebook/Meta)
- BERT (Google)
- GPT (OpenAI)
- Modelos em português para classificação de ofensividade

### Compartilhando Seus Próprios Modelos

Você também pode treinar seu próprio modelo e compartilhá-lo na plataforma HuggingFace, permitindo que outras pessoas o usem da mesma forma.
