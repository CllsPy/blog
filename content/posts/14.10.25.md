## Um exemplo simples, mas complicado
Mikolov et al. (2013) propuseram o **Word2Vec**, que representa palavras em vetores.  
Palavras semelhantes ficam próximas no espaço vetorial.

```python
import numpy as np
from numpy.linalg import norm

A = np.array([2,1,2,3,2,9])
B = np.array([3,4,2,4,5,5])

cosine = np.dot(A,B)/(norm(A)*norm(B))
print("Cosine Similarity:", cosine)
```




## A monalisa da inteligência artificial
Em 2017, a Google apresentou um trabalho que mudou para sempre o campo do Processamento de Linguagem Natural: **Attention Is All You Need**, de Vaswani et al.  
Esse estudo introduziu um novo paradigma — o **mecanismo de atenção**, base dos modelos modernos de linguagem.

Para entender, imagine que você está em uma sala cheia de pessoas conversando. Alguém te faz uma pergunta sobre história. Você não prestará atenção em todos os sons, apenas nas falas relevantes — aquelas vindas dos professores de história. O mecanismo de atenção faz exatamente isso: ele “decide” quais partes do texto são mais importantes para o contexto atual, priorizando-as durante o processamento.

Este conceito deu origem à arquitetura **Transformers**, um modelo que substituiu redes recorrentes (RNNs e LSTMs) e tornou possível treinar sistemas que compreendem longos trechos de texto com muito mais eficiência.  
O Transformer é a espinha dorsal de modelos como **BERT**, **GPT**, **RoBERTa** e **T5**.

Matematicamente, o mecanismo de atenção calcula a relevância entre palavras utilizando **vetores de consulta (query)**, **chave (key)** e **valor (value)**.  
O resultado é uma ponderação que indica quanto cada palavra deve “olhar” para as demais.

Em resumo:
- Ele aprende **contexto**.  
- É totalmente paralelizável.  
- Escala melhor que modelos sequenciais.  
- É a base dos grandes modelos de linguagem atuais.

### Pré-processamento

```python
def preprocessor(text):
    text = re.sub('<[^>]*>', '', text)
    emoticons = re.findall('(?::|;|=)(?:-)?(?:\)|\(|D|P)', text)
    text = (re.sub('[\W]+', ' ', text.lower()) + ' '.join(emoticons).replace('-', ''))
    return text
```




### Tokenização

```python
porter = PorterStemmer()

def tokenizer(text):
    return text.split()

def tokenizer_porter(text):
    return [porter.stem(word) for word in text.split()]
```
